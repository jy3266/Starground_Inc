## 탄소 데이터 콘솔

**배출 현황** — 1990–2023 국가 총배출량 추이와 2030/2035 NDC·2050 탄소중립 목표 경로, 분야별·에너지 세부 배출, 17개 시도 타일 카토그램.

**이동 경로** — 3단계 Sankey로 분야 → 활동 부문 → 최종 소비 귀속까지의 탄소 흐름을 추적합니다. 전환(발전) 부문 배출 213.0 Mt를 전력을 실제로 소비한 부문에 재배분하면 산업 부문의 실질 배출이 180.0 Mt에서 338.3 Mt로 늘어납니다. 지역 간 전력 이동과 전력자급률도 함께 표시합니다.

**배출권 등록·거래** — 사업자 등록 → 감축 실적 제출 → MRV 3단계 검증 → Proof Token 발행 → 오더북 거래까지의 전 과정을 실행할 수 있습니다. 블록 해시는 브라우저의 Web Crypto SHA-256으로 실제 계산되며 작업증명 루프도 실제로 돕니다.

> ⚠️ 거래·등록 기능은 **데모 시뮬레이션**입니다. 원장은 브라우저 localStorage에만 저장되며, 실제 배출권 거래나 법적 효력이 있는 등록이 아닙니다.
